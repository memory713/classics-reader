# 🏥 岐黄医馆 — 经营系统设计 v8

> ✨ **完整实现**：坐诊/升级/搬迁/家具/药柜 均已上线
> 162章内经 × 473味药材 × 18城搬迁 × 100级医馆 × 唯一家具
> 声望=经验 → 升级 | 金钱=装备 → 买家具（坐诊增益+挂机补贴）

---

## 一、设计原则

1. **研读→解锁题库** — 读一章，解锁该章的坐诊考题
2. **坐诊→原文短语→选解析** — 病人说原文短语，选对解析=治愈，对=声望+金钱，错=扣声望
3. **声望→升级** — 消耗声望升级医馆，达标可搬迁至大城
4. **金钱→家具** — 买家具，每件家具提供坐诊增益 + 每小时少量挂机金钱
5. **药材→套装** — 集齐某类药材→该类对应章节题目永久加成

## 二、三种货币

| 货币 | 获取途径 | 消耗途径 | 类比 |
|------|---------|---------|------|
| 心神 | 每日+50、采药全对+50 | 研读-10/章、坐诊-5/次 | 体力 |
| 声望 | 坐诊+10(对)/-5(错)、研读+50/章 | 升级医馆 | 经验值 |
| 金钱 | 主动坐诊（主）+ 家具挂机（辅） | 买家具、搬迁城市 | 金币 |

## 六、坐诊系统

### 出题规则
1. 从已研读的章节中随机选一章
2. 从该章的「解析」数据中随机取一条，用原文短语作为病人自述
3. 4选1解析，选项来自其他章节的解析内容

### 声望
| 行为 | 声望 |
|------|------|
| 坐诊答对 | +10 |
| 坐诊答错 | -5 |
| 研读一章 | +50 |

## 九、可视化诊室设计

### 9.1 概述

在医馆页面增加一个横截面诊室视图。购买家具后自动摆放到房间对应位置，形成一个**可看的、动态的诊室**。搬迁城市时背景风格变化（乡村竹屋→府城瓦房→京城红墙）。

### 9.2 布局分区（自下而上 6 层）

手机端竖屏浏览，从下往上滚动展示诊室全貌。每层横向排列该层家具，未购买的位置显示灰色虚线框，点击跳转购买。

```
第6层 · 门面      [🏮灯笼]  [🏆醫聖金匾]  [🔔铜铃]  [🏛️牌楼]
  ──────────────── 屋檐/天花板 ────────────────
第5层 · 陈设      [🖼️杏林匾]  [🗺️舆图]  [🌸插花]
  ──────────────── 墙壁中部 ────────────────
第4层 · 诊辅      [🪟屏风]  [🛏️诊疗床]  [📚书架]
  ──────────────── 诊室中后部 ────────────────
第3层 · 药区      [🏺药碾]  [🍶药壶]  [☕茶具]
  ──────────────── 药柜上方台面 ────────────────
第2层 · 药柜      [🌿 百草药柜 · 多层隔板]
  ──────────────── 独立视觉核心 ────────────────
第1层 · 诊区      [🪑诊桌]  [🪑医者椅]
  ──────────────── 最底层 · 坐诊核心 ────────────────
```

### 9.3 百草药柜 — 药区核心

药柜不再是纯 UI 列表，而是**诊室中的实体家具**，也是整个药柜系统的视觉载体。

**药柜展示逻辑：**
- 药柜占据诊室下层大块区域，分为多层隔板
- 每个隔板对应一个药材分类（21 套）
- 收集进度通过**隔板上的药瓶/药包数量**体现
  - 0% → 空隔板，落灰
  - 1~50% → 零散几包药材
  - 51~99% → 半满，标签可见
  - 100% → 满架 + 套装发光特效 + 分类铭牌点亮
- 点击药柜任意位置 → 跳转至完整的百草药柜页面（即 Achievements.vue）
- 点击某个分类隔板 → 直接跳转到药柜页面对应分类位置（高亮滚动）

**搬迁影响：**
- 搬到高级城市后药柜外观升级（竹柜→红木柜→金丝楠木柜+雕花）
- 药材收集进度保留，但柜子样式随城市变化

### 9.5 诊室状态反馈

- **空闲状态**：诊桌无人，药童（小动画）在药柜和诊桌之间走动
- **坐诊中**：诊桌处出现病人 + 医者对坐，药柜闪烁（正在抓药）
- **药材收集进度**：药柜隔板逐渐丰满，全收集时有庆祝粒子效果
- **家具组合**：药柜紧邻诊桌时，每次坐诊额外触发"抓药"动画，诊金小幅加成
